Liberar a pesquisa por este celular

O botão deixa um pedido no GitHub, que o Mac atende. Para isso, crie uma chave uma única vez:

  1. Abra github.com/settings/personal-access-tokens/new
  2. Em Repository access, escolha Only select repositories → digamazon
  3. Em Permissions, dê Actions: Read and write e Contents: Read-only
  4. Gere e cole a chave aqui

A chave fica guardada só neste aparelho e só é enviada ao GitHub.
